# 火星实验室前端

整页沉浸场景，默认观察前处理与分析区。滚轮缩小展开完整基地，拖动探索；科研、记录、AI 工作、资源和对照通过顶部悬浮入口查看。

已接入本轮 **Single** 的正式结束记录：运行 `01b44445-1215-4e53-8c97-67fe27458055`，终态 tick 2400，98 个物理操作、74 个遥测通道、10 条原始数据和 4 条分析记录。Multi 尚无结束报告，当前没有读取它的世界数据库，也没有操作实验进程。

## 打开

双击本目录的 `打开火星实验室.cmd`，或用浏览器直接打开 `dist/index.html`。页面已经内嵌 Single 数据，无需启动 DeepWorks、sidecar、代理、前端服务器或模型。

当前默认数据文件由 `config.json` 的 `defaultData` 指向 `records/single-v06.json`。修改源码后重新构建：

```bash
node 'E:/deepworks比赛/viewer/scripts/build.mjs'
```

也可以构建指定数据包，生成一个可以独立保存的网页：

```bash
node 'E:/deepworks比赛/viewer/scripts/build.mjs' --data 'E:/deepworks比赛/viewer/records/pair.json' --out 'E:/deepworks比赛/viewer/dist/pair.html'
```

如需 HTTP 访问，可选静态服务器仅绑定 `127.0.0.1`，只提供已经构建的 HTML：

```bash
node 'E:/deepworks比赛/viewer/scripts/serve.mjs' --port 4178
```

## 查看方式

- 默认局部；鼠标滚轮向外缩小、向内放大，以鼠标位置为锚点；空地拖动平移。
- 点器材展开浮动详情；双击或“聚焦器材”放大。器材列表可以通过键盘选择所有 27 个设备与设施。
- 顶部科研、实验记录、AI 工作、资源和对照打开浮层。关闭、Esc、点击外部都可返回；面板打开期间冻结观看时间，关闭后保留镜头与观看位置。
- “场景”里切换世界、跳转区域、查看器材列表与来源、调整名称和减少动态效果。
- “回看”打开逻辑时间工具。支持播放、逐事件、拖动到 tick、调整观看速度和返回终态。这里的 tick/s 只决定观看速度。
- “暂停观看”暂停部件动作与历史播放；不会暂停或恢复实验。
- 实验记录中搜索操作，点开后可“回看并定位”；原始数据和科研提交也可以跳转到关联记录。

器材有独立轮廓与阶段动作，装载、处理、维护、待机和异常分别表达。转子、移液头、检测扫描、机器人路线均受记录状态控制。健康标记与工作阶段分开；历史只显示可确认的故障信息，终态的清洁或校准标记不回填到过去。

机器人在器材接口处采用接驳姿态绘制，通过细引线连接真实锚点；物理坐标和路线不变。温室植株按记录中的 ID 与数量绘制，过去未记录的状态使用中性外观，终态的受压、损失和移除按快照表达。

## 导出与导入已结束运行

页面通过文件选择器读取 `mars-viewer/1` JSON 数据包。“导入与来源”可以一次选多个文件，也可追加其它世界。正式记录和集成样例不会混在一个数据包里；导入失败会保留原页面数据。

Multi 自然结算后，可以导出两个世界；输出文件必须是新文件名：

```bash
node 'E:/deepworks比赛/viewer/scripts/export-run.mjs' --multi 'E:/deepworks比赛/data/mars-multi' --single 'E:/deepworks比赛/data/mars-single' --out 'E:/deepworks比赛/viewer/records/pair.json'
```

然后在页面里导入 `pair.json`，或用前面的构建命令生成 `pair.html`。也可只使用 `--multi` 或 `--single` 导出单个世界。

导出器先核对 `final-report.json`、horizon 封存和公开运行清单。未完成时拒绝打开世界数据库。已结束运行通过 SQLite 一致备份生成临时副本，再只读提取，不拼接 DB/WAL 文件，不实例化 world 或 execution controller。

导出仅包含公开地图、器材与样品元数据、操作、已发生事件、路线、遥测、原始测量、科研记录、分析记录与公开结算。不会读取 secrets、凭据或 evaluator 目录；从物理快照提取公开字段，不向前端导出 world.config、样品隐藏浓度、质量 contacts、未来故障或隐藏历史。

## 历史范围

终态快照是完整的已导出公开状态。历史回看只还原事件支持的工作阶段、已接纳路线和已发生故障；终态库存、温度、清洁标记和作物状态不反向填充。未知状态在界面注明。

操作结束不代表科研结论正确。阶段进度与时间来自逻辑事件；未记录阶段结束时间时不显示精确百分比。阶段记录缺失的运行不会伪装成完整历史。

数据包保存每个来源的事件序号，按原有序号保留同 tick 内顺序，不将不同数据库的序号拼成统一事实顺序。对照页核对版本、truth/salt/scenario/case/protocol 身份、horizon 和 decisionTicks；这些是清单配对检查，不是重新计算隐藏评估。

## 开发与验证

原生 ES modules、SVG 等距绘制、CSS 与 Node.js 24 内置模块，无需安装前端依赖。构建器只打包本目录拥有的模块，生成单个 HTML；运行时 CSP 禁止网络连接与模型/实验控制请求。`records/` 是公开数据导出，`fixtures/` 是独立集成样例，`.work/` 是临时一致副本与测试材料。

- `src/layout.js`：公开布局、器材目录与任务名称。
- `src/data.js`：数据校验、操作关联、阶段与路线恢复、配对检查。
- `src/scene-art.js`、`src/scene.js`：艺术场景、数据驱动部件、镜头与屏幕空间标签。
- `src/panels.js`、`src/charts.js`、`src/app.js`：悬浮页面、图表、导入和观看控制。
- `scripts/export-run.mjs`：已结束运行的只读导出。
- `scripts/build.mjs`：独立网页构建；`--demo` 明确构建样例页面。

运行数据、回看、导出、构建与静态服务测试：

```bash
npm --prefix 'E:/deepworks比赛/viewer' test
```

浏览器检查需要本机已有 Playwright 和 Chrome；通过 `MARS_VIEWER_PLAYWRIGHT` 指定已有模块目录，不下载浏览器、不调用模型。脚本为 `scripts/check-browser.mjs`，检查真实记录页面、所有标签页、原始数据、回看、导入与模式切换、图表悬停、桌面与窄屏。截图及结果在 `artifacts/`。

构建独立样例网页：

```bash
node 'E:/deepworks比赛/viewer/scripts/build.mjs' --demo --out 'E:/deepworks比赛/viewer/dist/demo.html'
```
