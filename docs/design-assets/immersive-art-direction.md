# 火星实验室：沉浸页面设计方向

本轮决定：场景铺满窗口，默认停在前处理与分析区；向外滚轮连续缩小到完整基地。科研、记录、AI 工作、资源与对照从顶部悬浮入口打开，关闭后保持原镜头。

## 视觉参数

- 岩地 `#985F50`：来自火星地貌，只用于世界中的土地与岩石。
- 暮影 `#474653`：远处地形与建筑投影，保留空气感。
- 瓷白 `#DEE7E5`：仪器亮面和建筑上表面。
- 钛灰 `#778F98`：仪器侧面、支架和金属边缘。
- 深海蓝 `#243C46`：浮动控件、设备暗部和文字承托面。
- 工作光 `#73D1DF`：有操作依据的工作部件与运行图标。状态还使用不同图标和明确文字，不依赖色相区分。

界面主文字为 `#F2F5F3`，次文字 `#BBCACD`；浅色设备标记用 `#243C46`。完整运行版本的异常使用独立图标和状态文本。设计样页仅演示装载、处理、待机、完成，不引入一组相似的彩色状态。

字体：角落名称用本机宋体 / Noto Serif SC，字号 28–32px；按钮、名称、状态用 Microsoft YaHei / Noto Sans SC，正文 14px、短标签 13px。艺术性集中在世界构图与器材设计，界面文字保持安静。

## 写代码前的复核

上一稿仍是侧边导航、卡片中的场景与常驻详情列，无法满足“整个网页就是景色”。本轮移除三者，默认镜头从完整基地改为局部，底部时间轴折叠为观看按钮；只有主动查看记录时才展开时间工具。浮层保留同一个场景作为背景，关闭后恢复焦点。

避免把“艺术感”解释成满屏星点、霓虹边框、会漂浮的所有设备或自动运镜。记忆点只放在有光照层次的火星实验室微缩场景。样页使用稳定展示数据，与实验进程、数据库和正式时钟完全分开。
