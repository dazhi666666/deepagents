# 火星实验室前端重设计：整页场景，默认局部

日期：2026-11-16。版本：第二版，已完成正式接入。正式入口为 `E:/deepworks比赛/viewer/dist/index.html`，已内嵌完成结算的 Single 记录。Multi 尚未提供结算报告，保持运行；该世界结束后可通过同一只读导出与导入通道接入。使用方法见 `../viewer/README.md`。

本版以用户最新要求为准：默认观察实验室局部，滚轮缩小才显示完整基地；场景占满整个网页；其它页面通过悬浮按钮查看；整体需要有艺术感。上一版的侧栏导航、卡片内场景、常驻详情列和默认全景布局作废。

## 1. 页面是什么样子

进入网页就进入火星实验室。默认镜头位于前处理与分析区，能直接认出分液站、离心机、筛查仪、确认仪和成像台；远处露出温室，近处有通道、样品和机器人。房间和地面延伸到浏览器边缘，没有包围场景的白色容器。

上方悬浮少量页面入口，左上角保留基地名称，右上角是场景设置。底部只有观看与镜头工具。未选择器材、未打开页面时，画面尽量完整。

```text
╭ 火星实验室       [科研  实验记录  AI 工作  资源  对照]      [场景] ╮
│                                                                  │
│           远处温室 / 生长架 / 玻璃与管线                          │
│                                                                  │
│       分液站         离心机                确认仪                  │
│                                                                  │
│               以局部实验室为主的整页场景                         │
│                      样品 / 运输机器人 / 通道                     │
│                                                                  │
│ 前处理与分析区            [暂停观看]                 [−][+][复位]  │
╰ 滚轮缩放，拖动探索                         设计样例 / 数据来源     ╯
```

不自动运镜。第一次打开直接进入清楚的局部视角；之后由用户控制观察位置。默认一次展示一个世界，正式接入后 Multi / Single 切换保留区域和镜头偏好。

## 2. 艺术方向：暮色中的科研站

艺术感集中在整个世界的构图、器材结构、材质与光影。远处是低对比的赤褐岩地，建筑和器材有干净的亮面与灰蓝侧面，温室植物提供少量自然色。设备工作灯保持克制，安静环境中可以看见科学工作正在发生。

| 元素 | 处理 |
| --- | --- |
| 空间 | 等距微缩场景，固定投影；房间、通道和设备共享同一个世界 |
| 光线 | 左上方固定主光，顶面明亮，侧面冷灰，底部接触阴影与方向投影相叠 |
| 材质 | 岩地粗粝、仪器瓷白、金属支架、局部半透明玻璃，各有明暗层次 |
| 构图 | 主实验器材形成清晰的视觉路径，临近房间被画面裁切，向外缩放才逐渐露出全貌 |
| 氛围 | 外部暮色与内部工作光形成层次；减少漂浮粒子和持续装饰性动画 |
| 界面 | 深海蓝色悬浮控件、明确文字、轻量图标；不再用卡片切分整个页面 |

基础色：岩地 `#985F50`、暮影 `#474653`、瓷白 `#DEE7E5`、钛灰 `#778F98`、浮层 `#243C46`、工作光 `#73D1DF`。岩地色只属于世界中的地貌，不作为每个按钮和状态的强调色。

角落名称采用本机宋体 / Noto Serif SC，按钮和器材名称使用 Microsoft YaHei / Noto Sans SC。字体资源不依赖外网。艺术性由场景承担，正文保持易读。

这份样稿是风格化矢量等距场景，验证视觉层次与交互方向。后续可在现有 Canvas 2D 绘制层复现材质、器材和阴影，无须为了改版先引入完整 3D 引擎。

## 3. 镜头与观察方式

| 操作 | 行为 |
| --- | --- |
| 首次打开 | 停在前处理与分析的局部；无侧栏和数据面板 |
| 滚轮向外 | 以鼠标所在位置为锚点连续缩小；逐渐看到相邻区域，再看到完整基地 |
| 滚轮向内 | 连续放大局部，保持鼠标锚点稳定 |
| 拖动空地 | 平移世界；松开停止，不自动回正 |
| 缩到全局 | 器材短标签退让为房间标签，点房间进入对应局部 |
| 点器材 | 高亮选中对象，按需展开浮动详情；不立即改变镜头 |
| 双击器材 / 聚焦 | 将该设备放大到清楚可辨的尺寸，并给详情留空间 |
| 回到实验室 | 恢复局部构图；不是默认复位到全景 |
| 场景菜单 | 跳到温室、水处理、实验室、保存、能源与机器人区域；调整名称与减少动态效果 |

镜头的缩放和平移是连续操作，不切换两个互不相干的“全景页”和“局部页”。放大后回到原区域、打开并关闭其它页面，都应保持观察上下文。小屏默认进一步收窄到实验室局部，并提供器材列表与缩放按钮。

## 4. 其它页面如何进入

顶部五个悬浮入口承接现有页面。打开后，实验室仍留在背景；关闭面板回到相同镜头、选择和观看位置。

| 悬浮入口 | 原页面内容 | 面板方式 |
| --- | --- | --- |
| 科研 | 运行总览、科研目标、原始数据、分析结果 | 可展开的宽浮层，分类标签切换 |
| 实验记录 | 物理操作、异常事件、公告与可用历史 | 记录列表；有结构化关联时可定位器材与样品 |
| AI 工作 | 固定团队、模型活动、角色工作 | 工作列表与角色详情 |
| 资源 | 能源、水路、温室 | 同一浮层内切换能源、水、作物分类 |
| 对照 | Multi / Single、评估与比较 | 宽浮层；不默认将场景分成两半 |
| 场景菜单 | 平面地图、区域跳转、名称和图层等查看工具 | 小菜单；需要详细地图时再打开浮层 |

原页面功能按内容重新组织，正式实施时迁入这些浮层。当前设计样页展示入口、面板、标签切换、器材定位和关闭行为，并未接入或搬迁原页面的数据模块。

### 面板规则

- 器材详情是窄浮层，桌面贴右，小屏从底部展开；未选中时收起。
- 分析、对照等需要更大阅读面积的内容使用宽浮层，可在正式版扩大至近全屏。
- 一次只展示一个主要内容面板，避免层层窗口遮住场景。
- 关闭按钮、Esc 与遮罩点击均可退出；焦点返回打开入口。
- 面板内部滚动不缩放后面的场景，关闭时不重置镜头。
- 历史时间工具只在有可用历史、用户主动查看时展开；底部不常驻密集时间轴。

## 5. 器材必须可辨认

| 器材 | 轮廓与结构 | 工作动作 |
| --- | --- | --- |
| 自动分液站 | 外露龙门架、移液头、多孔板与前方托盘 | 装载时托盘进入；处理时移液头运动；待机停靠 |
| 离心机 | 大圆形转子窗口、低体机身、前控制区 | 处理时转子转动，待机静止；同一画面即可比较 |
| 筛查仪 | 低矮宽体与水平多孔托盘 | 托盘装载与横向扫描有明确阶段 |
| 确认仪 | 高体结构、竖向检测单元、独立样品仓 | 与筛查仪保持不同轮廓，处理与维护分别表达 |
| 成像台 | 开放镜头架和可见样品面 | 仅成像期间开启工作照明与扫描 |
| 水路 | 储水罐、透明滤芯、泵分别设计 | 有依据才显示水量与流动，不默认一直旋转 |
| 冷藏与冷冻 | 可辨舱门、载物口、高低柜体 | 强调交接；温度来自实际记录 |
| 温室 | 四个舱体、植株、灯架与灌溉点 | 生长与压力状态来自记录；维护、灌溉按实际操作触发 |
| 机器人 | R1/R2/R3 编号、轮式底盘与载货托盘 | 运输、交接、停靠不同；真实模式沿已接纳路线移动 |

名称和工作短语放在屏幕空间，字号不随镜头一起缩小。局部显示主要器材名称；全局只保留区域和关键异常。选中与活动对象优先保留，重叠标签避让。屋顶不封住观察，前墙低剖面，被选设备的遮挡物局部退让。

## 6. 动画与状态

工作阶段和健康标记分别保存。处理中且“下次使用前需清洗”可以同时成立，维护标记不能直接抹掉真实的工作阶段。

- 待机：部件停靠，状态文字明确。
- 装载：托盘或样品进入，有起止。
- 处理：转子、移液头、检测单元按各自结构工作。
- 完成：动作结束，出现完成符号；只表示操作完成。
- 维护：清洗、校准、维修独立表达。
- 等待、受阻、故障、限电、取消：停止相应工作动作，写出实际原因。
- 状态未记录：保留中性轮廓，不补造动作。

状态同时有动作、符号和文字，颜色辅助。样页用同一冷色工作光配不同图形，避免依赖一组相近色辨认阶段。正常运行、装载与待机可同时比较。

“暂停观看”统一暂停部件动画。样页提供设计状态切换，方便比较轮廓与动作；真实记录模式只接受事件与状态驱动，不提供修改实验状态的按钮。未记录的移液针精确路径、转速、关节和微观机构只可作视觉解释，不能伪装成物理测量。

## 7. 现有实现需要改哪里

现有场景可复用的是等距投影、渲染分层、交互拾取和地图关联；页面外壳与主要器材需要重做。

| 现状 | 源码位置 | 需要改变 |
| --- | --- | --- |
| 整幅地图适配 | `scene/scene.ts` 的 fitFor | 新增实验室局部初始镜头；缩小后自然露出全局 |
| 分析设备共用盒体 | `scene/devices.ts` 的 instrument 匹配与绘制 | 拆分筛查、确认、分析与成像的主体轮廓 |
| 名称默认关闭且偏小 | `public/mars/base.js`、`scene/readouts.ts` | 屏幕空间标签、按缩放改变密度、常态保留关键名称 |
| 动画随时间循环 | `scene/devices.ts`、`scene/elements.ts` | 由工作阶段控制部件运动、停靠与观看暂停 |
| 可用性与活动阶段不一致 | `api/foundation.ts` 与 isActive | 独立的工作阶段模型加健康标记 |
| 选中只更新 ID | `public/mars/base.js` | 浮动器材详情、关联记录、主动聚焦 |
| 其它页面有独立路由 | `public/mars/index.js` | 内容模块迁入悬浮入口和浮层容器 |

## 8. 与当前实验的关系

正式源码与构建产物位于 `E:/deepworks比赛/viewer/`。地图按 `mars/layout.ts` 的四列三行区域与器材锚点迁移。设计材料保留在 docs，集成样例独立放在 viewer/fixtures；真实模式由已导出记录驱动。

本轮已通过 SQLite 一致备份和只读字段投影导出结束的 Single：终态 tick 2400，98 个物理操作、74 个遥测通道、10 条原始数据与 4 条分析记录。页面内嵌公开数据后可独立打开，不调用模型或控制接口，不暴露凭据与隐藏评估字段。Multi 没有结算报告，导出器不会打开它的世界数据库。

已从源码确认实验记录包含 operation-accepted / processing / finished、robot-route-accepted / settled、系统操作事件与部分 telemetry。最终投影不能直接改小 tick 充当历史；实际可回看的范围要在导出时核验，缺失状态不得补造。观看节奏不改变正式实验的 12 tick 与 720 / 1800 / 2400 规则。

## 10. 验收重点

- 默认打开就是清楚的局部，没有导航侧栏、白色场景卡片或常驻详情占位。
- 滚轮缩小能连续看到完整基地；再次放大保留锚点；拖动与缩放不改变实验状态。
- 在 1440×900 窗口下主要器材轮廓、名称与阶段清楚；主要结构在灰度下也能区分。
- 关闭任一页面浮层后，观察位置、选择和观看位置保持不变。
- 装载、处理和待机设备有明确区别，暂停时所有工作部件同时停止。
- 全局标签、局部标签和选中标签有不同密度；关键名称不缩成小字。
- 小屏提供器材列表和缩放按钮，浮层适应窗口，支持键盘焦点、Esc 和减少动态效果。
- 真实模式只显示有记录支持的内容；当前实验代码、数据和运行进程不因设计工作发生变化。
